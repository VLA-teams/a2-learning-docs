# 快速开始


这里把平台文档、环境配置、实验操作和问题记录放在同一个入口。

## 第一次阅读

1. 阅读[智元 A2 v2.1 开发指南](/platform/agibot-a2)，核对设备和软件版本。
2. 按[环境配置](/setup/)准备开发机、连接方式和依赖。
3. 在[仿真与运动控制](/simulation/)验证基础流程。
4. 部署模型时进入[VLA 模型部署](/vla/)。
5. 把完整过程写入[实验操作手册](/handbook/)，同步[实验进展](/updates/progress)。

## 查找文档

左侧六个模块可折叠。顶部搜索支持标题与正文检索，桌面端可用 Ctrl / Command + K 打开。
