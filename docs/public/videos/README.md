# 视频目录

这个目录存放**操作录屏、实验回放、演示动画**等视频文件，构建时会原样复制到网站根目录，
所以文件 `a2-joint-panel-demo.mp4` 对应的访问地址是 `/videos/a2-joint-panel-demo.mp4`。

## 什么时候用这个目录

适合放：

- 机器人动作效果的录屏（抓取、行走、关节转动）
- 仿真环境的操作流程回放
- 网页示教面板的使用演示
- 故障现象的视频证据（比如「抖动」比文字描述清楚得多）

**不建议**把视频当正文主体。视频不能搜索、加载慢、手机上流量大，
重要信息仍应写成文字步骤，视频作为补充。

## 引用方式

视频**不会自动播放**，用 HTML 标签引入，控制条由浏览器提供：

~~~html
<video src="/videos/a2-joint-panel-demo.mp4" controls preload="metadata" width="100%"></video>

图 1：面板启动后点击「启用仿真控制」的完整过程。
~~~

如果只想放一个下载链接（小文件、手机端加载慢时更合适）：

~~~markdown
- [操作录屏（MP4，12 MB）](/videos/a2-joint-panel-demo.mp4)
~~~

## 上传规则

| 项目 | 要求 |
| --- | --- |
| 文件名 | 用英文或拼音，不要中文、空格、`#`、`?` |
| 单个文件 | **建议不超过 25 MB**（GitHub 网页上传上限） |
| 格式 | 录屏用 `.mp4`（H.264 编码），避免 `.mov`、`.avi` |
| 时长 | 建议 30 秒以内，只保留关键片段 |
| 内容 | 必须打码，见下方提醒 |

## 视频太大怎么办

视频比图片容易超限。按大小处理：

| 大小 | 做法 |
| --- | --- |
| ≤ 25 MB | 网页直接上传（用 `.mp4`，先压缩） |
| 25–100 MB | 用 Git 命令行推送，或请维护者代传 |
| > 100 MB | **不要放进仓库**，传到外部平台（B 站、对象存储），文档里只放链接 |

压缩建议：

- 录屏工具（OBS、Windows 自带录屏）直接设成 1080p / 30fps，不要录 4K
- 用 [HandBrake](https://handbrake.fr/) 压缩，预设选「Fast 1080p30」，通常能小一半
- 只剪需要的那一段，不要整段上传

**注意**：视频会长期留在 Git 历史里，即使以后删除，仓库体积也不会变小。
宁可先压缩或外链，也不要直接推大文件。

## 打码提醒

视频打码比截图麻烦，但更需要做——录屏很容易带出终端窗口里的：

- `hostname`、`whoami` 输出的用户名
- IP 地址、SSH 连接地址
- Docker 容器 ID、设备序列号
- 浏览器地址栏里的内网地址

处理方式：录制时就把这些窗口挪开或最小化；已经录好的用剪映等工具打码后再上传。
拿不准就先问维护者。
