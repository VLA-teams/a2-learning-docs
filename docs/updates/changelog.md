# 更新日志


## 2026-10-17 · 界面提示系统与阅读体验优化

- 新增页面状态条：由 frontmatter 的 `status / author / date` 自动生成，显示状态、维护人、更新日期和编辑入口；移除 16 个页面里的手写「内容状态」提示块。
- 统一提示框配色：`info / tip / warning / danger` 四类语义色，明暗主题各一套；提示文字对比度提升到 4.5:1 以上，小字不小于 12px。
- 新增页面底部反馈条与站点页脚；优化 404 文案与样式。
- 阅读体验：正文 14.5px/1.9、表格全宽且窄屏可横向滚动、代码块关闭行号并支持中文复制提示、侧栏产品卡修复换行。
- 文案统一：搜索无结果、404、空表格占位等提示改为「一句话说清 + 给下一步」。
- 首页 `<title>` 重复问题修复。

## 2026-10-17 · 协作方式升级：GitHub 网页 + PR 审核

- 面向组员：重写[如何更新文档](/contribute)，改为网页优先流程（无需安装 Git / Node.js），补充提交分支、PR 检查、合并发布和常见问题。
- 面向维护者：更新[发布与部署](/deployment)，新增邀请成员、保护 `main`、试点验收、审核清单、合并策略和回滚流程。
- PR 模板改为通用格式，增加版本、敏感信息、链接和新页面注册的自查项。
- README 更新协作方式、当前状态与目录结构。
- 说明：邀请成员、保护 `main`、试点 PR **尚未执行**，待新版本上传 GitHub 后完成测试。
